## Materials & techniques (site glossary)

| term | EN | de glossary lead-in |
|---|---|---|
| Aluminium oxide (Al₂O₃) | Aluminium oxide (Al₂O₃) | Das gängigste Abriebsmittel­korn für Bänder und Scheiben: zäh, gut schneidig, geeignet für Metall, Holz und generelles Finish. |
| ANSI grit scale | ANSI grit scale | Alte nordamerikanische Körnungs­nummern. |
| Backing (cloth) | Backing (cloth) | Ein Baumwoll-/Gewebe­träger, der das Abriebsmittel­korn in Bändern trägt. |
| Backing (polycotton) | Backing (polycotton) | Poly-Baumwoll-Gewebe­träger: ein Kompromiss aus Festigkeit und Flexibilität für Allzweck­bänder. |
| Belt | Belt | Eine durchgehende Schleifkorn­schleife auf einem Gewebe­träger, für Schleifmaschinen verwendet zum Schleifen, Finish und Entgraten. |
| Blending (weld) | Blending (weld) | Eine Schweißnaht glätten, damit sie sich in das umgebende Metall einfügt — typischerweise ein erster Durchgang mit Flapscheibe oder Band, dann feinere Körnungen. |
| Closed coat | Closed coat | Ein engschliffenes Kornlayout mit wenig freiem Raum; das Band widersteht dem Verharzen bei härterem Material. |
| Debur / Deburring | Debur / Deburring | Entfernen von Graten und kleinen Vorsprüngen, die durch Schnitte, Sägen oder Schleifen bleiben. |
| Dust collection / dust extraction | Dust collection / dust extraction | Abriebsstoff­staub am Werkstück entfernen — über Anlegeraustritte, offenmaschige Scheiben oder lokale Absaugung. |
| Flap disc | Flap disc | Eine Scheibe aus überlappenden Schleifflaps, flexibel, für Schleifen, Aufheben und Finish auf Winkelschleifern. |
| FEPA grit scale | FEPA grit scale | Die ISO 848 (FEPA)-Körnungs­skala in P-Notation (z. |
| Grit | Grit | Die Nenngröße des Abriebsmittel­korns: höhere Zahlen sind feiner. |
| Hook & loop | Hook & loop | Das Klett-Befestigungssystem für Scheiben: die Scheibe wird auf einen Klett­anleger aufgesetzt. |
| Mesh / open-mesh | Mesh / open-mesh | Offenmaschige Scheiben haben Ausschnitte, durch die Staub austreten kann, und benötigen einen kompatiblen Anleger und eine Absaugung. |
| MOQ | MOQ | Mindestbestellmenge — wird zusammen mit Verfügbarkeit und Konditionen im Angebot bestätigt. |
| OEM / private label | OEM / private label | Original-Equipment-Herstellung / Eigenmarke: unsere Produkte unter Ihrer Marke, Ihren Etiketten und Ihrer Verpackung. |
| PSA (pressure-sensitive adhesive) | PSA (pressure-sensitive adhesive) | Selbstklebender Träger (PSA): die Scheibe haftet direkt auf einem kompatiblen Anleger. |
| Sanding disc | Sanding disc | Ein flacher oder geflapter Abriebsmittel­kreis, der auf einem Anleger montiert wird zum Schleifen und Finish. |
| Silicon carbide (SiC) | Silicon carbide (SiC) | Karniv­korn (Silizium­karbid): sehr hart und scharf, geeignet für Glas, Keramik und Nichteisen­metalle. |
| Surface preparation | Surface preparation | Eine Oberfläche für Beschichtung oder Finish vorbereiten: Rost, Füllmasse oder altes Finish bis zu einem gleichmäßigen Profil entfernen. |
| Wet / dry grade | Wet / dry grade | Qualitäten, die bei Nass- oder Nass-Trocken­einsatz kühl und verharzungs­fest bleiben; Eignung wird im Angebot bestätigt. |
| X-weight cloth | X-weight cloth | Ein mittel­schwerer Gewebe­träger für Allzweck­bänder: fest und zugleich flexibel. |
| Zirconia | Zirconia | Zirkon­oxidalumini­umkorn: zäh und aggressiv für Metall­schleifen, Entgraten und Finish an Stahl. |
| Backer pad | Backer pad | Die Unterlage (Platte), auf der eine Scheibe liegt: Anlegerdurchmesser, Fläche (Klett) und Austritts­layout müssen zur Scheibe passen. |
