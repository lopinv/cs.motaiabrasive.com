## Materials & techniques (site glossary)

| term | EN | ja glossary lead-in |
|---|---|---|
| Aluminium oxide (Al₂O₃) | Aluminium oxide (Al₂O₃) | ベルト・ディスクで最も一般的な研粒：丈夫で削りやすく、金属・木材・一般仕上げに適する。 |
| ANSI grit scale | ANSI grit scale | 従来の北米グリット番号。同程度の粒径はFEPAスケールと異なります — すべての問い合わせで基準を明記してください。 |
| Backing (cloth) | Backing (cloth) | ベルトの研粒を支える綿・布ウェブ。ウェイト（例：Xウェイト）が柔軟性と耐荷重を決定。 |
| Backing (polycotton) | Backing (polycotton) | ポリ・コットンウェブベタ：汎用ベルトの強度と柔軟性のバランス。 |
| Belt | Belt | 布製ベタに研粒を配した連続ループ。ベルト機で研ぎ・仕上げ・バリ取りに使用。 |
| Blending (weld) | Blending (weld) | 溶接部を周囲の金属になめらかに統合する処理 — 通常フラップディスクまたはベルトでの一次仕上げ、その後細かいグリットで整えます。 |
| Closed coat | Closed coat | 開いた空間が少ない密着配列の研粒。硬い作業でも詰りにくい。 |
| Debur / Deburring | Debur / Deburring | 切断・鋸挽き・研ぎで残るバリや小さな突起の除去。 |
| Dust collection / dust extraction | Dust collection / dust extraction | 加工物からの研削粉の除去 — パッドポート・オープンメッシュディスク・局所排気にて。 |
| Flap disc | Flap disc | 重ねた研削フラップのディスク。柔軟で、角グラインダーでの研ぎ・磨き合わせ・仕上げに使用。 |
| FEPA grit scale | FEPA grit scale | P表記（例：P120）のISO 848（FEPA）等級スケール。多くの欧州・国際貿易で基準のスケール。 |
| Grit | Grit | 研削材の公称粒径：数字が大きいほど細かい。ベルト40〜800；ディスク60〜5000。 |
| Hook & loop | Hook & loop | ディスク用フック&ループ装着システム：ディスクはフック面パッドにカチッと付きます。 |
| Mesh / open-mesh | Mesh / open-mesh | オープンメッシュディスクは粉塵が通過する切り抜き窓があり、対応パッドと排気が必要。 |
| MOQ | MOQ | 最低発注数量 — 在庫状況と条件とともに、見積書で確定。 |
| OEM / private label | OEM / private label | OEM／プライベートラベル：当社の製品をあなたのブランド・ラベル・パッケージで提供。 |
| PSA (pressure-sensitive adhesive) | PSA (pressure-sensitive adhesive) | 圧感接着ベタ：ディスクが対応パッドに直接貼り付きます。 |
| Sanding disc | Sanding disc | パッドに装着し、サンディング・仕上げに使う、フラットまたはフラップ型研削円形工具。 |
| Silicon carbide (SiC) | Silicon carbide (SiC) | 炭化ケイ素（黒色）研粒：非常に硬く鋭く、ガラス・セラミック・非鉄金属に適する。 |
| Surface preparation | Surface preparation | 塗装または仕上げ前の表面準備：サビ・パテ・旧仕上げを均一なプロファイルまで除去。 |
| Wet / dry grade | Wet / dry grade | 湿式・ウェット&ドライでもクールで詰りにくい番手；適合性は見積で確認。 |
| X-weight cloth | X-weight cloth | 汎用ベルトの中ウェイト布製ベタ：丈夫でありながら柔軟。 |
| Zirconia | Zirconia | ジルコニアアルミナ研粒：強靭で攻撃的、鋼材の研ぎ・バリ取り・仕上げ向け。 |
| Backer pad | Backer pad | ディスクが載るベッカー盤：パッド直径・面（フック）・ポートレイアウトがディスクと一致することが必要。 |
