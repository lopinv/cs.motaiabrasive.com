## Materials & techniques (site glossary)

| term | EN | th glossary lead-in |
|---|---|---|
| Aluminium oxide (Al₂O₃) | Aluminium oxide (Al₂O₃) | เม็ดขัดที่พบมากที่สุดสำหรับสายพานขัดและจานเจียร: ทนทาน ใช้งานง่าย เหมาะกับโลหะ ไม้ และงานขัดผิวสำเร็จทั่วไป |
| ANSI grit scale | ANSI grit scale | มาตรฐานเลขเกรตแบบดั้งเดิมของอเมริกาเหนือ เม็ดขัดขนาดใกล้เคียงกันอาจต่างจากมาตรฐาน FEPA — ควรระบุมาตรฐานในทุกการสอบถาม |
| Backing (cloth) | Backing (cloth) | ผ้าใยฝ้าย/ผ้าที่ใช้เป็นฐานรองรับเม็ดขัดบนสายพานขัด น้ำหนักของฐานรองรับ (เช่น X-weight) กำหนดความยืดหยุ่นและความสามารถในการรับน้ำหนัก |
| Backing (polycotton) | Backing (polycotton) | ฐานรองรับแบบผ้าพอลีคอตตอน: สมดุลระหว่างความแข็งแรงและความยืดหยุ่นสำหรับสายพานขัดใช้งานทั่วไป |
| Belt | Belt | สายพานขัดเป็นวงแหวนต่อเนื่องของเม็ดขัดบนฐานรองรับ ใช้กับเครื่องขัดสายพานเพื่อการขัด ขัดผิวสำเร็จ และเก็บขอบ |
| Blending (weld) | Blending (weld) | การทำให้รอยเชื่อมเกลี้ยวเข้ากับโลหะโดยรอบข้าง โดยทั่วไปใช้ใบเจียรหรือสายพานขัดในขั้นแรก แล้วจึงใช้เกรตที่ละเอียดกว่า |
| Closed coat | Closed coat | การจัดเรียงเม็ดขัดแบบเคลือบชิด มีช่องว่างน้อย สายพานขัดจึงต้านการอุดตันเมื่อใช้งานหนัก |
| Debur / Deburring | Debur / Deburring | การกำจัดคราบฝ้ายและส่วนที่ยื่นเล็ก ๆ ที่หลงเหลือจากการตัด เลื่อย หรือขัด |
| Dust collection / dust extraction | Dust collection / dust extraction | การกำจัดฝุ่นวัสดุขัดบริเวณชิ้นงาน ผ่านรูแบ่งลมของแผ่นรอง จานเจียรตาข่ายแบบเปิด หรือระบบดูดฝุ่นเฉพาะจุด |
| Flap disc | Flap disc | จานเจียรประกอบด้วยใบวัสดุขัดที่ซ้อนทับกัน มีความยืดหยุ่น ใช้กับเครื่องขัดมุมในการขัด ขัดเกลี่ย และขัดผิวสำเร็จ |
| FEPA grit scale | FEPA grit scale | มาตรฐานการจัดเกรดตาม ISO 848 (FEPA) ในรูปแบบ P (เช่น P120) เป็นมาตรฐานที่ใช้ทั่วไปในการค้าระหว่างยุโรปและระหว่างประเทศ |
| Grit | Grit | ขนาดเม็ดขัดตามการระบุของวัสดุขัด: ตัวเลขยิ่งสูงยิ่งละเอียด สายพานขัด 40–800; จานเจียร 60–5000 |
| Hook & loop | Hook & loop | ระบบยึดแบบตะขอกับผ้าตีนตุ๊กแกสำหรับจานเจียร: จานเจียรติดเข้ากับแผ่นรองที่มีผิวตะขอได้ทันที |
| Mesh / open-mesh | Mesh / open-mesh | จานเจียรตาข่ายแบบเปิดมีช่องตัดเพื่อให้ฝุ่นผ่านได้ จึงต้องใช้แผ่นรองและระบบดูดฝุ่นที่เข้ากันได้ |
| MOQ | MOQ | จำนวนขั้นต่ำในการสั่งซื้อ (MOQ) ระบุไว้พร้อมข้อเสนอ พร้อมกับสถานะการจัดหมายและเงื่อนไขการใช้งาน |
| OEM / private label | OEM / private label | การผลิตเป็นอุปกรณ์ส่วนประกอบต้นฉบับ (OEM) / สินค้าแบรนด์ของคุณ: ผลิตภัณฑ์ของเราภายใต้แบรนด์ ฉลาก และบรรจุภัณฑ์ของคุณ |
| PSA (pressure-sensitive adhesive) | PSA (pressure-sensitive adhesive) | ฐานรองรับกาวแบบ PSA (กาวไวต่อความดัน): จานเจียรติดกับแผ่นรองที่เข้ากันได้ได้โดยตรง |
| Sanding disc | Sanding disc | วัสดุขัดรูปทรงกลมแบบแผ่นเรียบหรือแบบใบเจียร ติดตั้งบนแผ่นรองสำหรับการขัดและขัดผิวสำเร็จ |
| Silicon carbide (SiC) | Silicon carbide (SiC) | เม็ดขัดคาร์ไบด์ซิลิคอน: แข็งและคมมาก เหมาะกับแก้ว เซรามิก และโลหะที่ไม่ใช่เหล็ก |
| Surface preparation | Surface preparation | การเตรียมผิวให้พร้อมรับการเคลือบหรือขัดผิวสำเร็จ: กำจัดสนิม สารอุด หรือผิวเดิมออกให้ได้โครงสร้างสม่ำเสมอ |
| Wet / dry grade | Wet / dry grade | เกรดที่คงความเย็นและต้านทานการอุดตันเมื่อใช้งานเปียกหรือเปียก/แห้ง ควรยืนยันความเหมาะสมกับใบเสนอราคา |
| X-weight cloth | X-weight cloth | ฐานรองรับแบบผ้าน้ำหนักกลางสำหรับสายพานขัดใช้งานทั่วไป: แข็งแรงแต่ยืดหยุ่น |
| Zirconia | Zirconia | เม็ดขัดอะลูมิน่าซิร์โคเนีย: ทนทานและมีฤทธิ์แรง เหมาะกับการขัดโลหะ เก็บขอบ และขัดผิวสำเร็จบนเหล็ก |
| Backer pad | Backer pad | แผ่นรองรับที่จานเจียรวางอยู่: เส้นผ่านศูนย์กลางของแผ่นรอง ผิวหน้า (ตะขอ) และตำแหน่งรูแบ่งลมต้องตรงกับจานเจียร |
