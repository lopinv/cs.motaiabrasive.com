## Materials & techniques (site glossary)

| term | EN | ms glossary lead-in |
|---|---|---|
| Aluminium oxide (Al₂O₃) | Aluminium oxide (Al₂O₃) | Biji abrasif paling umum untuk tali dan cakera: tahan lasak, mudah digunakan, sesuai untuk logam, kayu dan kerja kemaskan umum. |
| ANSI grit scale | ANSI grit scale | Sistem penomboran grit lama Amerika Utara. |
| Backing (cloth) | Backing (cloth) | Web kapas yang membawa biji abrasif pada tali. |
| Backing (polycotton) | Backing (polycotton) | Asas web politeks-kapas: keseimbangan antara kekuatan dan kelenturan untuk tali umum. |
| Belt | Belt | Gelung berterusan biji abrasif pada asas web, digunakan pada mesin tali untuk pengasahan, kemaskan dan buang burr. |
| Blending (weld) | Blending (weld) | Melicinkan kimpalan supaya menyatu dengan logam di sekelilingnya — biasanya langkah pertama dengan cakera flap atau tali, kemudian grit lebih halus. |
| Closed coat | Closed coat | Susunan biji salutan rapat dengan ruang terbuka sedikit; tali mengurangkan risiko tersumbat pada kerja lebih berat. |
| Debur / Deburring | Debur / Deburring | Membuang burr dan tonjolan kecil yang tertinggal selepas memotong, menggergaji atau mengasah. |
| Dust collection / dust extraction | Dust collection / dust extraction | Mengbuang habuk abrasif pada benda kerja — melalui port pad, cakera mesh terbuka atau penyedutan setempat. |
| Flap disc | Flap disc | Cakera keping flap abrasif yang bertindih dan lentur, untuk pengasahan, ratakan simpulan kimpalan dan kemaskan pada pengasah sudut. |
| FEPA grit scale | FEPA grit scale | Skala gred ISO 848 (FEPA) dalam notasi P (contoh P120). |
| Grit | Grit | Saiz biji nominal bagi abrasif: angka lebih tinggi bermakna lebih halus. |
| Hook & loop | Hook & loop | Sistem lampiran hook & loop untuk cakera: cakera diklik pada pad berpermukaan cangkuk. |
| Mesh / open-mesh | Mesh / open-mesh | Cakera mesh terbuka mempunyai tingkap tertindih untuk laluan habuk, memerlukan pad dan sistem penyedutan yang sesuai. |
| MOQ | MOQ | Kuantiti pesanan minimum — disertakan bersama sebut harga, ketersediaan dan terma. |
| OEM / private label | OEM / private label | Pembuatan peralatan asal / jenama sendiri: produk kami dengan jenama, label dan pembungkusan Anda. |
| PSA (pressure-sensitive adhesive) | PSA (pressure-sensitive adhesive) | Asas perekat sensitif tekanan: cakera melekat terus pada pad yang sesuai. |
| Sanding disc | Sanding disc | Bulatan abrasif rata atau berflap yang dipasang pada pad untuk pengasahan dan kemaskan. |
| Silicon carbide (SiC) | Silicon carbide (SiC) | Biji silikon karbida: sangat keras dan tajam, sesuai untuk kaca, seramik dan logam bukan besi. |
| Surface preparation | Surface preparation | Menyediakan permukaan untuk salutan atau kemaskan: membuang karat, pengisi atau salutan lama sehingga profilnya konsisten. |
| Wet / dry grade | Wet / dry grade | Gred yang kekal sejuk dan mengurangkan risiko tersumbat dalam penggunaan basah atau basah/kering; sahkan kesesuaian bersama sebut harga. |
| X-weight cloth | X-weight cloth | Asas kain berat sederhana untuk tali umum: kukuh tetapi lentur. |
| Zirconia | Zirconia | Biji alumina zirkonium: tahan lasak dan agresif untuk pengasahan logam, buang burr dan kemaskan pada keluli. |
| Backer pad | Backer pad | Plat asas tempat cakera diletakkan: diameter pad, muka (cangkuk) dan susunan port mesti sepadan dengan cakera. |
