## Materials & techniques (site glossary)

| term | EN | id glossary lead-in |
|---|---|---|
| Aluminium oxide (Al₂O₃) | Aluminium oxide (Al₂O₃) | Butiran abrasif paling umum untuk sabuk dan piringan: tangguh, mudah dikerjakan, cocok untuk logam, kayu, dan finising umum. |
| ANSI grit scale | ANSI grit scale | Penomoran grit Amerika Utara lama. |
| Backing (cloth) | Backing (cloth) | Kain berbasis katun yang menopang butiran abrasif pada sabuk. |
| Backing (polycotton) | Backing (polycotton) | Backing web poly-katun: keseimbangan kekuatan dan kelenturan untuk sabuk serbaguna. |
| Belt | Belt | Lingkar butiran abrasif yang tidak putus-putus pada backing web, digunakan pada mesin sabuk untuk penggerindaan, finising, dan penghilangan burr. |
| Blending (weld) | Blending (weld) | Melicinkan las agar menyatu dengan logam sekitarnya — biasanya jalur pertama dengan piringan flap atau sabuk, lalu grit yang lebih halus. |
| Closed coat | Closed coat | Tata letak butiran tertutup rapat dengan ruang terbuka sedikit; sabuk tahan menyumbat pada pekerjaan yang lebih keras. |
| Debur / Deburring | Debur / Deburring | Menghilangkan burr dan tonjolan kecil yang ditinggalkan oleh pemotongan, pemotongan gergaji, atau penggerindaan. |
| Dust collection / dust extraction | Dust collection / dust extraction | Menghilangkan debu abrasif pada benda kerja — melalui port pad, piringan jaring terbuka, atau ekstraksi lokal. |
| Flap disc | Flap disc | Piringan dari tumpukan lipatan abrasif yang saling tumpang tindih, lentur, untuk penggerindaan, blending, dan finising pada gerinda sudut. |
| FEPA grit scale | FEPA grit scale | Skala gradasi ISO 848 (FEPA) dalam notasi P (mis. |
| Grit | Grit | Ukuran nominal butiran abrasif: angka lebih tinggi berarti lebih halus. |
| Hook & loop | Hook & loop | Sistem pemasangan hook-and-loop untuk piringan: piringan terpasang pada pad dengan permukaan hook. |
| Mesh / open-mesh | Mesh / open-mesh | Piringan jaring terbuka memiliki jendela potongan agar debu dapat melewati, dan membutuhkan pad serta ekstraksi yang kompatibel. |
| MOQ | MOQ | Minimum order quantity (MOQ) — disertakan bersama penawaran, disertai ketersediaan dan syarat. |
| OEM / private label | OEM / private label | Pembuatan alat asli (OEM) / private label: produk kami dengan merek, label, dan kemasan Anda. |
| PSA (pressure-sensitive adhesive) | PSA (pressure-sensitive adhesive) | Backing perekat sensitif tekanan: piringan menempel langsung pada pad yang kompatibel. |
| Sanding disc | Sanding disc | Lingkaran abrasif datar atau berflap yang dipasang pada pad untuk pengamplasan dan finising. |
| Silicon carbide (SiC) | Silicon carbide (SiC) | Butiran karbida silikon: sangat keras dan tajam, cocok untuk kaca, keramik, dan logam non-ferrous. |
| Surface preparation | Surface preparation | Menyiapkan permukaan untuk pelapisan atau finishing: menghilangkan karat, filler, atau lapisan lama hingga profil yang konsisten. |
| Wet / dry grade | Wet / dry grade | Grade yang tetap dingin dan tahan menyumbat untuk penggunaan basah atau basah/kering; tetapkan kesesuaiannya melalui penawaran. |
| X-weight cloth | X-weight cloth | Backing kain berat menengah untuk sabuk serbaguna: kuat namun lentur. |
| Zirconia | Zirconia | Butiran zirkonia alumina: tangguh dan agresif untuk penggerindaan, penghilangan burr, dan finising logam. |
| Backer pad | Backer pad | Pelat backing tempat piringan duduk: diameter pad, permukaan (hook), dan tata letak port harus cocok dengan piringan. |
