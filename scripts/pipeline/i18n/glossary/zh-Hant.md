## Materials & techniques (site glossary)

| term | EN | zh-Hant glossary lead-in |
|---|---|---|
| Aluminium oxide (Al₂O₃) | Aluminium oxide (Al₂O₃) | 砂帶與砂紙片最常用的磨料顆粒：強韌、切削性佳，適合金屬、木材與通用精修。 |
| ANSI grit scale | ANSI grit scale | 北美舊版粒度編號體系。相近目數與 FEPA 體系不同 — 每筆詢盤都註明標準。 |
| Backing (cloth) | Backing (cloth) | 承載砂帶磨料顆粒的棉織基布。克重（如 X 重）決定柔順性與負載量。 |
| Backing (polycotton) | Backing (polycotton) | 滌棉基布：強度與柔順性兼顧，通用砂帶用。 |
| Belt | Belt | 磨料顆粒覆於基布上形成的連續環，用於砂帶機磨削、精修與除毛刺。 |
| Blending (weld) | Blending (weld) | 將熔接接合平滑融入周圍金屬 — 通常先用百葉片或砂帶做第一道，再換細粒度。 |
| Closed coat | Closed coat | 密式塗布：顆粒排布緊密、空隙極少；砂帶在硬材工件上抗堵塞。 |
| Debur / Deburring | Debur / Deburring | 去除切割、鋸切或磨削留下的毛刺與小突起。 |
| Dust collection / dust extraction | Dust collection / dust extraction | 排出工件處的磨料粉塵 — 經打磨盤排風口、網眼砂紙片或局部集塵。 |
| Flap disc | Flap disc | 由重疊磨片層疊而成的柔性砂片，裝於角磨機用於磨削、混合與精修。 |
| FEPA grit scale | FEPA grit scale | ISO 848（FEPA）分級體系，P 制編號（如 P120）。歐洲與國際貿易的預設體系。 |
| Grit | Grit | 磨料顆粒的標稱尺寸：數字越大越細。砂帶 40–800；砂紙片 60–5000。 |
| Hook & loop | Hook & loop | 砂紙片的鉤環附著系統：砂紙片直接扣合在鉤面打磨盤上。 |
| Mesh / open-mesh | Mesh / open-mesh | 開放式網眼砂紙片帶開孔窗口供粉塵通過，需搭配相容打磨盤與集塵。 |
| MOQ | MOQ | 最低訂購量 — 隨報價與供應情況、條款一併確認。 |
| OEM / private label | OEM / private label | 原始設備製造 / 自有品牌：我們的產品以您的品牌、標籤與包裝供應。 |
| PSA (pressure-sensitive adhesive) | PSA (pressure-sensitive adhesive) | 壓敏膠（PSA）基體：砂紙片直接黏附在相容打磨盤上。 |
| Sanding disc | Sanding disc | 平面或百葉式砂片，裝在打磨盤上用於砂磨與精修。 |
| Silicon carbide (SiC) | Silicon carbide (SiC) | 碳化矽磨料：極硬且鋒利，適合玻璃、陶瓷與非鐵金屬。 |
| Surface preparation | Surface preparation | 為塗裝或精修做表面準備：除鏽、除補土或舊漆至一致的剖面。 |
| Wet / dry grade | Wet / dry grade | 濕式或濕乾使用下保持低溫、抗堵塞的粒度等級；適用性以報價單確認。 |
| X-weight cloth | X-weight cloth | 通用砂帶用的中重量棉布基（X 重）：強韌且柔順。 |
| Zirconia | Zirconia | 鋯剛玉磨料：強韌且切削力強，用於鋼件磨削、除毛刺與精修。 |
| Backer pad | Backer pad | 砂紙片安裝其上的背盤：盤徑、盤面（鉤面）與排風口配置必須與砂紙片匹配。 |
