## Materials & techniques (site glossary)

| term | EN | fa glossary lead-in |
|---|---|---|
| Aluminium oxide (Al₂O₃) | Aluminium oxide (Al₂O₃) | رایج‌ترین دانه ساینده برای نوارها و دیسک‌ها: مقاوم، کارآمد، مناسب برای فلز، چوب و صاف‌کاری عمومی. |
| ANSI grit scale | ANSI grit scale | شماره‌گذاری قدیمی گریت در آمریکای شمالی. |
| Backing (cloth) | Backing (cloth) | شبکه‌ای از پنبه یا پارچه که دانه ساینده را روی نوارها حمل می‌کند. |
| Backing (polycotton) | Backing (polycotton) | زیرلایه شبکه‌ای پلی‌کoton: تعادلی میان استحکام و انعطاف‌پذیری برای نوارهای کاربرد عمومی. |
| Belt | Belt | حلقه‌ای پیوسته از دانه ساینده روی زیرلایه شبکه‌ای که در ماشین‌های نواری برای سنگ‌زنی، صاف‌کاری و براده‌گیری استفاده می‌شود. |
| Blending (weld) | Blending (weld) | هم‌ترازکردن جوش به‌گونه‌ای که با فلز اطراف یکدست شود — معمولاً در گام نخست با دیسک فلپ یا نوار ساینده و سپس با گریت‌های ریزتر. |
| Closed coat | Closed coat | چیدمان دانه با پوشش فشرده و فضای باز اندک؛ نوار در کارهای سنگین‌تر در برابر گرفتگی مقاوم است. |
| Debur / Deburring | Debur / Deburring | حذف پلیسه‌ها و برجستگی‌های کوچک باقی‌مانده از برش، اره‌کاری یا سنگ‌زنی. |
| Dust collection / dust extraction | Dust collection / dust extraction | جمع‌آوری گرد و غبار ساینده در محل قطعه کار — از طریق منافذ صفحه پشتیبان، دیسک‌های توری باز یا مکش موضعی. |
| Flap disc | Flap disc | دیسکی از پره‌های ساینده هم‌پوشان و انعطاف‌پذیر که برای سنگ‌زنی، هم‌ترازکردن جوش و صاف‌کاری روی سنگ فرز استفاده می‌شود. |
| FEPA grit scale | FEPA grit scale | مقیاس درجه‌بندی ISO 848 (FEPA) با نماد P (برای نمونه P120). |
| Grit | Grit | اندازه اسمی دانه ساینده: هرچه عدد بزرگ‌تر باشد، دانه ریزتر است. |
| Hook & loop | Hook & loop | سیستم اتصال hook & loop برای دیسک‌ها: دیسک روی صفحه پشتیبان چنگکی محکم می‌شود. |
| Mesh / open-mesh | Mesh / open-mesh | دیسک‌های توری باز دارای پنجره‌های برش‌خورده برای عبور گرد و غبار هستند و به صفحه پشتیبان سازگار و سیستم مکش نیاز دارند. |
| MOQ | MOQ | حداقل مقدار سفارش (MOQ) — همراه با پیش‌نویس قیمت، در دسترس بودن و شرایط ارائه می‌شود. |
| OEM / private label | OEM / private label | تولید تجهیزات اصل / برند اختصاصی: محصولات ما با برند، برچسب و بسته‌بندی شما. |
| PSA (pressure-sensitive adhesive) | PSA (pressure-sensitive adhesive) | زیرلایه چسب حساس به فشار (PSA): دیسک مستقیماً روی صفحه پشتیبان سازگار می‌چسبد. |
| Sanding disc | Sanding disc | دایره‌ای تخت یا فلپ‌دار از مواد ساینده که روی صفحه پشتیبان برای سایش و صاف‌کاری نصب می‌شود. |
| Silicon carbide (SiC) | Silicon carbide (SiC) | دانه کاربید سیلیکون: بسیار سخت و تیز، مناسب شیشه، سرامیک و فلزات غیرآهنی. |
| Surface preparation | Surface preparation | آماده‌سازی سطح برای پوشش‌دهی یا پرداخت نهایی: حذف زنگ‌زدگی، بتونه یا پوشش قدیمی تا دستیابی به یکنواختی سطح. |
| Wet / dry grade | Wet / dry grade | گریدهایی که در کاربرد تر یا تر/خشک خنک می‌مانند و در برابر گرفتگی مقاوم هستند؛ تناسب آن‌ها را در پیش‌نویس قیمت تأیید کنید. |
| X-weight cloth | X-weight cloth | زیرلایه پارچه‌ای با وزن متوسط برای نوارهای کاربرد عمومی: مقاوم و در عین حال انعطاف‌پذیر. |
| Zirconia | Zirconia | دانه آلومینیای زیرکونیا: مقاوم و تهاجمی برای سنگ‌زنی فلز، براده‌گیری و صاف‌کاری فولاد. |
| Backer pad | Backer pad | صفحه پشتیبانی که دیسک روی آن قرار می‌گیرد: قطر صفحه، سطح (چنگکی) و چیدمان منافذ باید با دیسک مطابقت داشته باشد. |
