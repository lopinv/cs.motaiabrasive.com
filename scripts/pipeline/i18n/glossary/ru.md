## Materials & techniques (site glossary)

| term | EN | ru glossary lead-in |
|---|---|---|
| Aluminium oxide (Al₂O₃) | Aluminium oxide (Al₂O₃) | Самое распространённое зерно для лент и дисков: прочное, поддающееся работе, подходит для металла, дерева и общей финишной обработки. |
| ANSI grit scale | ANSI grit scale | Устаревшая северноамериканская нумерация зерна. |
| Backing (cloth) | Backing (cloth) | Хлопковая/тканая основа, несущая абразивное зерно на лентах. |
| Backing (polycotton) | Backing (polycotton) | Основа из поли-хлопка: баланс прочности и гибкости для универсальных лент. |
| Belt | Belt | Непрерывный контур абразивного зерна на тканой основе, используется на ленточных станках для шлифовки, финишной обработки и зачистки заусенцев. |
| Blending (weld) | Blending (weld) | Сглаживание сварного шва, чтобы он плавно переходил в окружающий металл, — обычно первый проход лепестковым кругом или лентой, затем более мелкое зерно. |
| Closed coat | Closed coat | Плотная посадка зерна с минимальным свободным пространством; лента сопротивляется забиванию при более жёстких работах. |
| Debur / Deburring | Debur / Deburring | Удаление заусенцев и небольших выступов, оставшихся после резки, пиления или шлифовки. |
| Dust collection / dust extraction | Dust collection / dust extraction | Удаление абразивной пыли на заготовке — через порты патча, сетчатые диски или локальную вытяжку. |
| Flap disc | Flap disc | Диск из нахлёстных абразивных лепестков, гибкий, для шлифовки, выравнивания и финишной обработки угловыми шлифовальными машинами. |
| FEPA grit scale | FEPA grit scale | Шкала классификации ISO 848 (FEPA) с P-обозначением (например, P120). |
| Grit | Grit | Номинальный размер зерна абразива: чем больше число, тем мельче зерно. |
| Hook & loop | Hook & loop | Крючко-петельная система крепления дисков: диск защёлкивается на патч с крючками. |
| Mesh / open-mesh | Mesh / open-mesh | Сетчатые диски имеют вырезанные окна для прохода пыли, требуют совместимого патча и системы отвода. |
| MOQ | MOQ | Минимальный объём заказа — подтверждается в котировке вместе с наличием и условиями. |
| OEM / private label | OEM / private label | OEM / private label: наша продукция под вашим брендом, этикетками и упаковкой. |
| PSA (pressure-sensitive adhesive) | PSA (pressure-sensitive adhesive) | Клеящаяся (адгезивная) основа: диск приклеивается напрямую на совместимый патч. |
| Sanding disc | Sanding disc | Плоский или лепестковый абразивный круг, устанавливается на патч для шлифовки и финишной обработки. |
| Silicon carbide (SiC) | Silicon carbide (SiC) | Зерно карбида кремния: очень твёрдое и острое, подходит для стекла, керамики и цветных металлов. |
| Surface preparation | Surface preparation | Подготовка поверхности к покрытию или финишной обработке: удаление ржавчины, шпатлёвки или старого лака до однородного профиля. |
| Wet / dry grade | Wet / dry grade | Фракции, которые остаются прохладными и устойчивыми к забиванию в мокром или мокро-сухом режиме; пригодность подтверждается в котировке. |
| X-weight cloth | X-weight cloth | Средневесовая тканая основа для универсальных лент: прочная и в то же время гибкая. |
| Zirconia | Zirconia | Зерно диоксида циркония: прочное и агрессивное, для шлифовки металла, зачистки и финишной обработки стали. |
