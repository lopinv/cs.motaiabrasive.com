## Materials & techniques (site glossary)

| term | EN | ca glossary lead-in |
|---|---|---|
| Aluminium oxide (Al₂O₃) | Aluminium oxide (Al₂O₃) | El gran abrasiu més habitual en cintes i discs: resistent, fàcil de treballar, adequat per a metall, fusta i acabats generals. |
| ANSI grit scale | ANSI grit scale | Numeració de grans del Nord d'Amèrica, d'origen. |
| Backing (cloth) | Backing (cloth) | Llona de cotó/tela que porta el gran abrasiu a les cintes. |
| Backing (polycotton) | Backing (polycotton) | Suport de llona de poli-cotó: equilibri de resistència i flexibilitat per a cintes d'ús general. |
| Belt | Belt | Un bucle continu de gran abrasiu sobre un suport de llona, que s'utilitza en màquines de cinta per a esmolat, acabat i desbastat. |
| Blending (weld) | Blending (weld) | Suavitzar una soldadura perquè es fusioni amb el metall envoltant — normalment un primer passat amb un disc de flocs o una cinta, i després grans més fins. |
| Closed coat | Closed coat | Distribució de grans estancada amb poc espai obert; la cinta resisteix l'ensorrament en treballs durs. |
| Debur / Deburring | Debur / Deburring | Eliminar bavos i petites prominències que deixen el tall, el serració o l'esmolat. |
| Dust collection / dust extraction | Dust collection / dust extraction | Eliminar la pols abrasiva a la peça — a través de les obertures de la placa, discs de malla oberta o extracció local. |
| Flap disc | Flap disc | Un disc de flocs abrasius superposats, flexible, per a esmolat, mescla i acabat amb esmols angulars. |
| FEPA grit scale | FEPA grit scale | L'escala de graus ISO 848 (FEPA) en notació P (per exemple, P120). |
| Grit | Grit | La mida nominal del gran d'un abrasiu: a més gran el número, més fi. |
| Hook & loop | Hook & loop | Sistema de fixació de ganxet i velcro per a discs: el disc s'encaixa a una placa amb cara de ganxet. |
| Mesh / open-mesh | Mesh / open-mesh | Els discs de malla oberta tenen finestres retallades perquè hi passi la pols, i necessiten una placa i una extracció compatibles. |
| MOQ | MOQ | Comanda mínima — arriba amb l'oferta, juntament amb la disponibilitat i les condicions. |
| OEM / private label | OEM / private label | Fabricació per al constructor original (OEM) / marca pròpia: els nostres productes amb la teva marca, etiquetes i empacament. |
| PSA (pressure-sensitive adhesive) | PSA (pressure-sensitive adhesive) | Adhesiu de pressió com a suport: el disc s'adhereix directament a una placa compatible. |
| Sanding disc | Sanding disc | Un cercle abrasiu pla o de flocs muntat sobre una placa, per a escarrassat i acabat. |
| Silicon carbide (SiC) | Silicon carbide (SiC) | Gran de carburs de silici: molt dur i agut, adequat per a vidre, ceràmica i metalls no ferrosos. |
| Surface preparation | Surface preparation | Posar una superfície a punt per a recobriment o acabat: eliminar oxids, farciment o acabat antic fins a obtenir un perfil coherent. |
| Wet / dry grade | Wet / dry grade | Graus que es mantenen freds i resisteixen l'ensorrament en ús sec o humit/sec; confirma l'adequació amb el pressupost. |
| X-weight cloth | X-weight cloth | Un suport de tela de pes mitjà per a cintes d'ús general: fort i alhora flexible. |
| Zirconia | Zirconia | Gran d'alumina de zirconi: resistent i agressiu per a l'esmolat de metall, el desbastat i l'acabat d'acer. |
| Backer pad | Backer pad | La placa de suport sobre la qual reposa el disc: el diàmetre de la placa, la cara (ganxet) i el patró d'obertures han de coincidir amb el disc. |
