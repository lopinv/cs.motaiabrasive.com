## Materials & techniques (site glossary)

| term | EN | ar glossary lead-in |
|---|---|---|
| Aluminium oxide (Al₂O₃) | Aluminium oxide (Al₂O₃) | أكثر حبيبات الكاشط شيوعاً للأحزمة والأقراص: متينة وسهلة التشغيل، مناسبة للمعادن والخشب والتشطيب العام. |
| ANSI grit scale | ANSI grit scale | ترقيم حبيبية أمريكي شمالي قديم. |
| Backing (cloth) | Backing (cloth) | نسيج قطني يحمل حبيبة الكاشط في الأحزمة. |
| Backing (polycotton) | Backing (polycotton) | غلاف بولي-قطني: توازن بين القوة والمرونة للأحزمة متعددة الاستخدامات. |
| Belt | Belt | حلقة متواصلة من حبيبة الكاشط على غلاف نسيجي، تُستخدم في ماكينات الحزام للصقل والتشطيب وإزالة الكشط. |
| Blending (weld) | Blending (weld) | تليين الحزام حتى يندمج في المعدن المحيط — عادةً مرور أولي بقرص ذنبلي أو حزام، ثم حبيبية أخص. |
| Closed coat | Closed coat | ترتيب كاشط شبه مغلق بمساحات مفتوحة قليلة؛ يقاوم الحزام الانسداد على مهام أصعب. |
| Debur / Deburring | Debur / Deburring | إزالة الكشط والنقاط البارزة الصغيرة التي يخلفها القطع أو التنزيل أو الصقل. |
| Dust collection / dust extraction | Dust collection / dust extraction | إزالة غبار الكاشط من القطعة العاملة — عبر منافذ المساند، أقراص الشبكة المفتوحة، أو السحب المحلي. |
| Flap disc | Flap disc | قرص من أذنابل كاشطة متراكبة، مرن، للصقل والتلويح والتشطيب على ماكينات الصقل القمري. |
| FEPA grit scale | FEPA grit scale | مقياس التصنيف ISO 848 (FEPA) بترميز P (مثل P120). |
| Grit | Grit | الحجم الاسمي لحبة الكاشط: الأرقام الأعلى أدق. |
| Hook & loop | Hook & loop | نظام الارتباط الهلالي والحلقي (Velcro) للأقراص: يُثبَّت القرص على مساند بوجه حلقي. |
| Mesh / open-mesh | Mesh / open-mesh | أقراص الشبكة المفتوحة لها نوافذ مقصوصة لتجاوز الغبار، وتتطلب مساند وسحب متوافقين. |
| MOQ | MOQ | الحد الأدنى للطلب — مؤكد في عرض السعر مع التوفر والشروط. |
| OEM / private label | OEM / private label | تصنيع المعدات الأصلية / علامة خاصة: منتجاتنا تحت علامتك وسماك وتغليفك. |
| PSA (pressure-sensitive adhesive) | PSA (pressure-sensitive adhesive) | غلاف لاصق ذاتي الضغط (PSA): القرص يلاصق مباشرة على مساند متوافق. |
| Sanding disc | Sanding disc | دائرة كاشطة مسطحة أو ذنبلية تُثبَّت على مساند للصنفرة والتشطيب. |
| Silicon carbide (SiC) | Silicon carbide (SiC) | حبيبة كاربيد السيليكون: صلبة حادة، مناسبة للزجاج والسيراميك والفلزات غير الحديدية. |
| Surface preparation | Surface preparation | إعداد السطح لتغليف أو تشطيب: إزالة الصدأ أو المعجون أو التشطيب القديم حتى مقطع موحّد. |
| Wet / dry grade | Wet / dry grade | درجات تبقى باردة ومقاومة للانسداد في الاستخدام الرطب أو الرطب/الجاف؛ أكّد الصلاحية في عرض السعر. |
| X-weight cloth | X-weight cloth | غلاف نسيجي متوسط الوزن للأحزمة متعددة الاستخدامات: قوي ومرن. |
| Zirconia | Zirconia | حبيبة زركونيا وألومينا: متينة وحادة لصقل المعادن وإزالة الكشط والتشطيب على الفولاذ. |
| Backer pad | Backer pad | صفيحة التثبيت التي يرتكز عليها القرص: قطر المساند والوجه (الحلقي) وتخطيط المنافذ يجب أن يطابق القرص. |
