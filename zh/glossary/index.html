磨料术语表

每个砂带、砂纸片与百叶规格背后的术语。

磨料耗材行业通用定义。具体订单的分级与基体细节以报价确认为准。

Aluminium oxide (Al₂O₃)
砂带与砂纸片最常用的磨料颗粒：坚韧、易切削，适用于金属、木材与通用精修。
ANSI grit scale
北美旧粒度编号体系。相近目数与 FEPA 体系不同——每次询盘都注明标准。
Backer pad
砂纸片坐落的背衬垫：垫径、垫面（钩面）与风口布局必须与片匹配。
Backing (cloth)
承载磨料颗粒的棉织基布，用于砂带。克重（如 X 重）决定柔韧性与承载力。
Backing (polycotton)
涤棉基布：强度与柔韧性均衡，通用于砂带。
Belt
磨料颗粒附着在基布上形成的连续环，用于砂带机磨削、精修与去毛刺。
Blending (weld)
将焊缝平滑并入周围金属——通常百叶片或砂带先做粗道，再换细粒度。
Closed coat
密实涂布：颗粒排布紧密、空隙小，在硬工件上抗堵塞。
Debur / Deburring
去除切割、锯切或磨削留下的毛刺与凸起。
Dust collection / dust extraction
在工件处排出磨料粉尘——经垫片风口、网眼片或局部吸尘。
FEPA grit scale
ISO 848（FEPA）P 制编号（如 P120）。欧洲与国际贸易的默认体系。
Flap disc
由层叠磨片组成的柔性片，装角磨机用于磨削、混合与精修。
Grit
磨料标称粒度：数字越大越细。砂带 40–800；砂纸片 60–5000。
Hook & loop
砂纸片魔术贴附着系统：片直接扣上魔术贴垫片。
Mesh / open-mesh
网眼片带开孔窗口供粉尘通过，需兼容垫片与吸尘。
MOQ
最低起订量——与可用性与条款一起在报价中确认。
OEM / private label
原始设备制造 / 贴牌：以您的品牌、标签与包装供应我们的磨料。
PSA (pressure-sensitive adhesive)
压敏胶基体：砂纸片直接粘在兼容垫片上。
Sanding disc
装在垫片上用于打磨精修的扁平或百叶磨片。
Silicon carbide (SiC)
碳化硅磨料：极硬锋利，适用于玻璃、陶瓷与有色金属。
Surface preparation
为涂装或精修做表面准备：除锈、除腻子、除旧漆至一致面形。
Wet / dry grade
湿式或干湿两用下保持低温、抗堵塞的等级；适用性与报价确认。
X-weight cloth
中克重布基，通用于砂带：强韧又柔韧。
Zirconia
氧化锆（锆刚玉）磨料：坚韧凶猛，用于钢件磨削、去毛刺与精修。
